The challenges

Every backend gets the same game and the same telemetry through one gateway. Each challenge asks one question, and the answers sit side by side. Nothing is ranked.

  1. 01

    Can you see the swing?

    High-density metrics

    Each player's motion is sent as a metric about every 100 ms. In the seconds before a player is knocked out, does the backend keep that detail, smooth it into coarse steps, or lose it?

  2. 02

    How deep can you go?

    Trace scale

    One game is one trace, and every round makes it bigger: 10 thousand spans, then 100 thousand, then a million. Up to which round can the backend still show the whole trace?

  3. 03

    Where did it go?

    Event structure

    The same moments, a player's warning and their death, are sent in three shapes: as a span, a span event and a log event. Does the backend find the same moment in every shape?

  4. 04

    Who saved them?

    Cross-trace correlation

    The AI game master makes its decision in one trace; the effect, like a shield on a player, lands in the game's trace. Can the backend join the two through a shared id and tell whether the player survived?

  5. 05

    What is happening?

    AI dashboard generation

    The same published prompts go to each backend's own AI assistant to build the game dashboard. Every panel is then checked against what really happened in the game.

  6. 06

    What did the game master cost?

    GenAI cost

    The AI game master calls a language model. How far down can the backend break down what those calls cost: in total, per caller, per game, per decision?

The challenges are still being built, so not all of them are playable yet.
